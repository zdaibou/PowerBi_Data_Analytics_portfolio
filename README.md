 

# Power BI Data Analytics Portfolio 

 

This repository contains a comprehensive Power BI project consisting of 6 production-ready dashboards analyzing business, operational, and HR datasets. 

 

## 📊 Dashboards & Insights Included 

 

1. **Sales & Profitability Analysis (Exercise 1):** Region-based business insights tracking revenue vs profit anomalies (high sales but negative profits in the East region). 

2. **Dream Business - Coffee Shop (Exercise 2):** Operational metrics tracking product sales, volumes, and revenue peaks for a modern cafe. 

3. **UK City Comparison (Extension 3):** Geographic and comparative data visualization using rank-based bar charts and distribution segments to spot regional market concentrations. 

4. **Netflix-Style Catalog Analysis (Extension 4):** Media streaming content assessment analyzing customer ratings, genres, and temporal releases. 

5. **Training Provider Performance (Extension 5):** Corporate KPI tracking evaluating the direct correlation between user satisfaction scores and course pass rates. 

6. **Recruitment Analytics (Extension 6):** HR analytics evaluating pipeline application volumes against specialized market salaries to spot talent shortages. 

 

## 🛠️ Tools Used 

- **Power BI Desktop:** Data modeling, report layout, and business intelligence data visualization. 

- **Microsoft Excel:** Raw data simulation, structuring, and formatting.
